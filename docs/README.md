# Документация
## Описание проекта
Проект содержит функции для расчёта файториала числа и последнего числа среди заданного количества чисел последовательности Фибоначчи.
## Описание функций
### 1. Факториал
- Выводит факториал заданного числа.
- Формулы:
    >**if n == 0: return 1\
    >else: return n * factorial(n - 1)**
- Пример вызова:
    >**factorial(3) -> 6**
### 2. Фибоначчи
- Возвращает последнее полученное число последовательности Фибоначчи после iter вычислений нового числа последовательности
- Формулы:
    ```python
    a = 0
    b = 1
    Цикл { c = a + b
    a = b
    b = c } - iter раз
    ```
- Пример вызова:
    >**fibonacchi(3) -> 3
    >fibonacchi(5) -> 8**
